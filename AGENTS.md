# Agent Instructions

Dieses Monorepo verwendet pnpm.

- Zum Formatieren des Codes immer `pnpm format` ausführen (Prettier, eine zentrale Config im Repo-Root).
- Zum Linten des gesamten Projekts `pnpm lint` ausführen.

Alle Pull Requests müssen diese Schritte ausführen und die Ergebnisse in der PR-Beschreibung dokumentieren.
